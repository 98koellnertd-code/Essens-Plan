# Essens-Plan

Wochen-Essensplan mit Einkaufsliste und aktuellen Supermarkt-Angeboten (Windows).

## Download

**Neueste Version:** https://github.com/98koellnertd-code/Essens-Plan/releases/latest

`Essens-Plan.exe` herunterladen und starten – keine Installation nötig. Zu jeder Version gehört
`SHA256SUMS.txt`; prüfen mit `certutil -hashfile Essens-Plan.exe SHA256`.

Das Programm sucht selbst nach Updates und installiert sie nur nach Rückfrage und mit passender Prüfsumme.

Mehr in [LIESMICH.txt](LIESMICH.txt), Änderungen in [CHANGELOG.md](CHANGELOG.md),
Veröffentlichen in [RELEASE.md](RELEASE.md).
